# Overzicht van AI-prompts voor wolfenstein3d-style-terminal

Dit bestand bevat alle prompts en verzoeken die aan de AI-assistent zijn gegeven voor dit project, chronologisch geordend met datum en toelichting.

================================================================================
Prompt 1 (8 september 2026, 10:46 CEST / 08:46 UTC)
================================================================================
make it so if you kill all enemies it shows like a victory thing and same
  make it like that cool droop down animations if you get what i mean

Toelichting:
Verzoek om een overwinningsscherm toe te voegen wanneer alle vijanden zijn verslagen, met een vallende ASCII-animatie.

================================================================================
Prompt 2 (12 oktober 2026, 10:05 CEST / 08:05 UTC)
================================================================================
Hallo Bo,

Ik heb net jouw Game getest in Docker. Ik heb hierbij een paar stukken aan feedback die ik graag aan jou mee wil geven.

De gameplay was zeer makkelijk omdat de enemies allemaal hetzelfde pad namen, dit maakte de game minder leuk. Het lijkt mij handig als de enemies verschillende paden kunnen nemen en niet allemaal op hetzelfde moment op je afkomen.

Wanneer ik alle enemies verslagen had moest ik de game weer helemaal opnieuw via Docker starten, het zou fijn zijn als je in de game een restart knop had. 

Ik hoop dat je wat hebt aan mijn feedback en dat je hiermee een betere game kan maken.

Met vriendelijke groet,
Timothey Hoff kan je dit toevoegen

Toelichting:
Feedback van tester Timothey Hoff verwerkt:
- Vijanden nemen verschillende paden om muren via tie-breaking per entiteit en ontwijken van bezette kaartvakken.
- Vijanden komen niet allemaal tegelijk door waarnemingsafstand (8 tegels) en snelheidsvariatie per entiteit.
- In-game herstartknop toegevoegd met de toets 'R' (herlaadt kaart en herstelt spelstatus).

Prompt 3 (12 oktober 2026, 10:18 CEST / 08:18 UTC)
================================================================================
so you now hard coded enemie spawns through enemy.c instead of reading it from the map file, also there is still no wave system, and enemies dont do damge so you cant really lose + can you update the gun ascii art to make it look better it kinda sucks now

Toelichting:
Vragen en verzoeken naar aanleiding van eerdere wijzigingen:
1. Verduidelijking dat spawns niet hardcoded zijn in enemy.c (worden nog steeds dynamisch uit map.txt gelezen; alleen in tests/enemy.c stonden vaste testposities).
2. Verbetering van het wapen: gecentreerd pistool in eerste-persoonsperspectief met gedetailleerde ASCII-art en mondingsvuuranimatie.
3. Toevoegen van vijandenschade (10 HP per melee-aanval) en een verliesscherm (Game Over) wanneer de speler 0 HP bereikt.

Keuze van de student via interactieve selectie:
"(Recommended) Eerst het wapen (ASCII-art verbeteren en centreren) en daarna vijandenschade/verliesscherm toevoegen"

================================================================================
Prompt 4 (12 oktober 2026, 10:25 CEST / 08:25 UTC)
================================================================================
a wave system??

Toelichting:
Verzoek om een wave-systeem toe te voegen.

Keuze van de student via interactieve selectie:
"(Recommended) 3 Waves om te winnen: elke wave worden vijanden iets sneller, je krijgt bonusmunitie na elke ronde, en na wave 3 behaal je de overwinning."

Resultaat:
- WaveMaxRounds = 3 met oplopende snelheid per wave.
- Spelers krijgen +24 bonuskogels na het overleven van elke ronde.
- HUD toont WAVE 1/3, 2/3, 3/3.
- Overwinning na het voltooien van wave 3.
